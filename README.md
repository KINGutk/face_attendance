# 🎓 Face Attendance System — Khushal Degree College

A Flask-based web application for automated face-recognition attendance.

## Features
- 🤖 Real-time Face Recognition Attendance
- 📸 3-Angle Student Registration (Front, Left, Right)
- 👨‍🏫 Multi-Role System (Admin, Professor, Student)
- 📊 Analytics Dashboard with attendance stats
- 📧 Email Notifications via Gmail SMTP
- 📝 Leave Management System
- ⏰ Auto-Absent Scheduler

## Tech Stack
- **Backend:** Flask + Python
- **Face Recognition:** dlib + face_recognition + OpenCV
- **Database:** MySQL (TiDB Serverless)
- **Email:** Gmail SMTP

## Default Login
- **Admin:** `admin` / `admin123`
